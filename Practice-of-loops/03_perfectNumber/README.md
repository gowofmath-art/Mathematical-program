# 3.	迴圏的練習-perfectNumber

一個數字若等於其所有因數的總和，則此數為perfect number。
找出100以內所有的完美數。
說明：6的因數為1, 2, 3，6=1+2+3，故6為完美數。

法一：正常作法雙for迴圈  
時間複雜度：$O(n^2)  

法二：i的部分只檢查到n的平方根，大大降低時間複雜度。  
時間複雜度：$O(n*n^(1/2))$  

法三：數論解法：利用梅森質數(Mersenne Prime)  
時間複雜度：$O(2^{x/2})$  
利用定理：若 2^p - 1 是一個梅森質數，那麼 2^(p-1)*(2^p - 1) 就必定是一個偶完美數  

原理：
1. 針對單一的 $p$，質數檢測的時間複雜度為 $O(2^{p/2})$
2. 外層迴圈將 $p$ 從 $2$ 走訪到 $x - 1$，總運算次數 $T(x)$ 即為每次質數檢測試驗次數的總和：
$$T(x) = \sum_{p=2}^{x-1} O(2^{p/2}) = 2^{2/2} + 2^{3/2} + 2^{4/2} + \dots + 2^{(x-1)/2}$$

這是一個公比 $r = \sqrt{2} \approx 1.414 > 1$ 的等比級數。
根據等比級數求和公式：$$\sum_{k=a}^{b} r^k = \frac{r^b \cdot r - r^a}{r - 1}$$因公比大於 1，總和的主導項（Dominant Term）完全取決於最後一項（即最大項）：
$$T(x) = O((\sqrt{2})^{x-1}) = O(2^{(x-1)/2}) = O(2^{x/2})$$
