# 7.	迴圏的練習-rabbit
老王養了一群兔子，若三隻三隻一數，剩餘一隻；若五隻五隻一數，剩餘三隻；若七隻七隻一數，剩餘二隻。試問兔子最少有幾隻。

很標準的 餘數問題

法一：單純的for迴圈
說穿了是暴力搜尋法，時間複雜度：$O(n)$ ，準確來說是從1開始搜尋直到找到為止，根據題目條件，可快可慢。

法二：while 迴圈，符合數學思想
```python 
x = 1
    while x % 5 != 3:
        x += 3

    while x % 7 != 2:
        x += 15

    return x
```
關鍵在於：
1. x除3於1：只需要看：1, 4, 7, 10, 13, ...
也就是每次x增加3。
2. 找到滿足x除5餘3：
此時這兩個條件會每隔$lcm(3,5)=15$重新出現。
所以接下來只需要看：13, 28, 43, 58, ...
3. 直到滿足 % 7 == 2。  

法三：逐次增長篩法（Step Sieve） 
不再從 $1$ 開始無腦 $+1$ 搜尋，而是每滿足一個同餘條件，就把步長放大，保證後續的搜尋絕不會破壞前幾步已經成立的結論。  
## 演算法核心概念：  
假設目前找到一個數 $ans$ 滿足了前 $k$ 個條件：$$ans \equiv r_i \pmod{m_i} \quad (\forall i \le k)$$  
如果將 $ans$ 加上 $\text{lcm}(m_1, m_2, \dots, m_k)$ 的任意倍數：$$(ans + c \times \text{step}) \pmod{m_i} = ans \pmod{m_i} = r_i$$  
餘數完全不會改變。  

因此，尋找下一個條件的解時，只要每次增加「前面所有模數的最小公倍數（即 step）」，就能在完全不破壞前項條件的前提下，逼近下一個條件。  

次數：$1->2 -> 9->16->23 -> 35$
降至 $2 + 3 + 1 = 6$ 次

法二：人工算好了 step。  
法三：由演算法自己算出來。  

法四：中國剩餘定理 (Chinese remainder theorem，CRT)
## 中國剩餘定理（Chinese Remainder Theorem, CRT）

我們有：
$$x \equiv 1 \pmod{3}$$
$$x \equiv 3 \pmod{5}$$
$$x \equiv 2 \pmod{7}$$

因為 $3,5,7$ 兩兩互質，所以令：
$$M = 3 \cdot 5 \cdot 7 = 105$$

再定義：
$$M_1 = \frac{105}{3} = 35$$
$$M_2 = \frac{105}{5} = 21$$
$$M_3 = \frac{105}{7} = 15$$

接著找各自的模反元素 $y_i$，使得：
$$M_i y_i \equiv 1 \pmod{m_i}$$

### 1. 求 $y_1$
$$35y_1 \equiv 1 \pmod{3}$$

因為：
$$35 \equiv 2 \pmod{3}$$

所以：
$$2y_1 \equiv 1 \pmod{3}$$

因此：
$$y_1 = 2$$

---

### 2. 求 $y_2$
$$21y_2 \equiv 1 \pmod{5}$$

因為：
$$21 \equiv 1 \pmod{5}$$

所以：
$$y_2 = 1$$

---

### 3. 求 $y_3$
$$15y_3 \equiv 1 \pmod{7}$$

因為：
$$15 \equiv 1 \pmod{7}$$

所以：
$$y_3 = 1$$
---

## CRT 構造解
根據中國剩餘定理：
$$x \equiv 1(35)(2)+3(21)(1)+2(15)(1)\pmod{105}$$

因此：
$$x \equiv 70+63+30 \pmod{105}$$

$$x \equiv 163 \pmod{105}$$

又因為：
$$163 \bmod 105 = 58$$

所以：
$$\boxed{x \equiv 58 \pmod{105}}$$

因此所有解皆可表示為：
$$x = 58 + 105k,\qquad k \in \mathbb{Z}$$

若要求兔子的最少正整數數量，則：
$$\boxed{58}$$
