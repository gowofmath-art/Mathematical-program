很標準的 餘數問題

法一：單純的for迴圈
說穿了是暴力搜尋法，時間複雜度：$O(n)$ ，準確來說是從1開始搜尋直到找到為止，根據題目條件，可快可慢。

法二：while 迴圈，符合數學思想
```python 
x = 1
    while x % 5 != 3:
        x += 3

    while x % 7 != 2:
        x += 15

    return x
```
關鍵在於：
1. x除3於1：只需要看：1, 4, 7, 10, 13, ...
也就是每次x增加3。
2. 找到滿足x除5餘3：
此時這兩個條件會每隔$lcm(3,5)=15$重新出現。
所以接下來只需要看：13, 28, 43, 58, ...
3. 直到滿足 % 7 == 2。
