# 2.	選擇性敘述的練習-salary

輸入便利商店工讀生的工作時數，並計算其薪資。  
60小時以內，時薪120元。  
61~80小時，以時薪1.25倍計算。  
81小時以上，以時薪1.5倍計算。  
說明：薪資以累計方式計算。若工時為90小時，則薪資為60*120 + 20*120*1.25 + 10*120*1.5元。  


## 方法比較

兩個做法都各自用python , javascript練習

| 方法 | 核心概念 | 優點 | 缺點 |
|---|---|---|---|
| if / elif | 條件分支 | 直觀易懂 | 程式碼較冗長 |
| math | 數學 | 優美且符合數學概念 | 不一定想得到 | 

## 我的觀察

種方法的時間複雜度在本題都可視為 O(1)，差異主要不在效能，只差在寫法上，在可讀性、擴充性與對問題的建模方式。
