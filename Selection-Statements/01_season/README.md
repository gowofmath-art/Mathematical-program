## 1.	選擇性敘述的練習-season

輸入月份1~12月，利用switch判斷相對應的季節春、夏、秋、冬並印出。若不在此範圍則印出”輸入錯誤”。

## 方法比較

以較為熟悉的python 示範不同作法，javascript以練習一個為主。

| 方法 | 核心概念 | 優點 | 缺點 |
|---|---|---|---|
| if / elif | 條件分支 | 直觀易懂 | 條件較冗長 |
| set | 集合歸類 | 可讀性佳 | 仍需要多個分支 |
| mapping | 索引映射 | 簡潔、無重複判斷 | 對映規則較隱晦 |

## 我的觀察

三種方法的時間複雜度在本題都可視為 O(1)，差異主要不在效能，只差在寫法上，在可讀性、擴充性與對問題的建模方式。
