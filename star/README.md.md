## 常見的星星題目  

在一開始學程式設計時，往往會遇到一類題目：「要求print出相應的*集合形成一個圖形，可能是等腰三角形、金字塔、沙漏、菱形等等」，我將這類題目稱為「星星題目」。  

## 老師的做法：  
老師的作法往往是：用字串"*" * 數個 再搭配 空格"_" * 數個，來決定每一行可以print出什麼。   
(這邊用等腰三角形來舉例，邊長為5的靠右邊的等腰三角形)  

程式碼如下：  

```python
n = 5
for x in range(n):
    print(" "*(n-x-1)+"*"*(x+1))
```

結果可以print出來：
```python
    *
   **
  ***
 ****
*****
```
這種方法相當直觀，也很適合處理基本圖形；但當圖形具有多條邊界、對稱結構或內外區域時，逐行計算空白與星號數量可能需要較多分類討論。   

## 我的思考與做法：直角坐標平面上的思考  

然而我有不同的觀點，用數學上的直角坐標平面作為思考，我將最後呈現的看作一個xy坐標平面，但這是一個特殊的坐標，在這個坐標之中$(0,0)$是左上方，而往右方移動對應到的是 $y坐標增加1單位$、而往下方移動對應到的是 $x坐標增加1單位$，那麼只要用直線方程式即可畫出相應的區塊。

更廣義的說：  
核心思想是 視為 直角坐標平面，把整張圖看成格點集合。  
只要找 $(x,y)\in S $ 的條件 ，S為所要生成的圖形。  

描述「整個平面上的點集條件」，接著就是解析幾何的工作了。

同一題的程式碼如下：  

```python
n = 5
for x in range(n):
    for y in range(n):
        if x+y >= n-1:
            print("*",end="")
        else:
            print(" ",end="")
    print()
```

所需要生成的就是右下的平面，所以，找出 x+y=n-1 的直線，其要得就是下半平面，也就是x+y≥n-1 的這部分。符合條件的就print("*")，沒有就是print("_")。

因此這類題目都可以這樣解決！  只要找到相應的方程式即可！
