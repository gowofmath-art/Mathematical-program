# Function Practice (Python / JavaScript)

本專案收錄基礎演算法與邏輯控制練習，聚焦於隨機採樣、字串解析、校驗碼驗證（Check Digit Validation）以及日曆排版邏輯。

---
各題說明：

### 1. 使用亂數產生驗証碼-verify
實作不同約束條件下的亂數邏輯。
(1)	產生四個數字，可以重覆  
(2)	產生四個數字，不可以重覆  
(3)	產生四個由數字和大寫英文字母組成  



### 2. 檢查身分證號碼是否正確-chkID
依據中華民國國民身分證統一編號邏輯進行字串校驗：
程式邏輯如下：  
(1)	檢查是否有十個字元，超過十個字元不准輸入  
(2)	檢查第一個字元是否為英文字母，若為小寫將其轉換成大寫  
(3)	檢查第二個字元是否為1或2數字  
(4)	檢查第三個至第十個字元是否為數字  
(5)	檢查最後一個檢查碼是否正確  
☺檢查碼的規則請查網路  


### 3. 日期的練習-MyCalendar
給兩個整數，第一個數字代表那一年，第二個數字代表那一月，列印出那一年那一月的月曆。  
提示：找出那年那個月1日是星期幾
