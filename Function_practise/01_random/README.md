# 1. 使用亂數產生驗証碼-verify
實作不同約束條件下的亂數邏輯。  
分別會有不同的做法：


### (1)	產生四個數字，可以重覆    
random-1-1  與 random-1-2  (不管是py or js都一樣的做法)  
直接從0-9的數字中隨機取一個，並且用字串加法加起來，重複4次。達到題目要求。  

有趣的是：python的1-2作法會比較快，但是javascript的1-2做法卻稍微慢一點。  

### (2) 產生四個數字，不可以重覆    
random-2-1：
採用「隨機猜測 > 重複則丟棄重抽」的想法
總期望迴圈次數為：$$E[T] = \sum_{i=1}^{4} \frac{1}{p_i} = 1 + \frac{10}{9} + \frac{10}{8} + \frac{10}{7} \approx 4.79 \text{ 次}$$

random-2-2：
優化：
random.sample 是專門設計用來處理「不重複抽樣」的函式，且保證這 P(10,4) 種結果的出現機率嚴格均等
期望值就是4次。



### (3)	產生四個由數字和大寫英文字母組成    
random-3-1：
母體集合包含 10 個數字與 26 個大寫字母，共 $N = 36$ 個字元。
兩者邏輯皆為「每次等機率抽取 1 個字元，並用字串加法累加，重複 4 次」。

數學觀點：
屬於「可重複抽樣」，每次抽取相互獨立。
樣本空間大小為：
$$|\Omega| = 36^4 = 1{,}679{,}616$$
每一種四碼組合出現的機率皆均等為：
$$P(X = x) = \frac{1}{36^4} \approx 5.95 \times 10^{-7}$$
