# 2. 檢查身分證號碼是否正確-chkID

依據中華民國國民身分證統一編號邏輯進行字串校驗：
程式邏輯如下：  
(1)	檢查是否有十個字元，超過十個字元不准輸入  
(2)	檢查第一個字元是否為英文字母，若為小寫將其轉換成大寫  
(3)	檢查第二個字元是否為1或2數字  
(4)	檢查第三個至第十個字元是否為數字  
(5)	檢查最後一個檢查碼是否正確  
☺檢查碼的規則請查網路：

# 輸入身分證，轉換數字s
1. 字母轉換：開頭的英文字母會根據對應表轉換為兩位數字。  
2. 賦予權重：將轉換後的數字與後續的數字展開，每一位數都有固定的「權重」。  
計算方式如下：字母轉換後的十位數*1+ 字母轉換後的個位數*9  
接下來的數字依序 * 8, 7, 6, 5, 4, 3, 2, 1  (第n碼乘上(10-n))  
3. 上述加總 後 加最後一碼 (檢查碼) 得到S
4. S為10的倍數 (若不是代表是錯誤的身分證)

思考方式：  
1. 首先：先轉為大寫，並且轉為list
2. 直接建立三個list：number , Eng , id_list (由於數字不連續也沒特別規律，這樣處理較為恰當)
3. 依序判斷(1)-(4) 的過程
4. 唯有(5) 較為特別，先用ord函數將大寫字母 A 到 Z 轉為對應的 ASCII 碼 (A為65 到 Z為90)  
5. 在進行檢查碼的判斷，我這邊使用sigma的形式進行，使得過程更加簡潔好看
